How to get your mindmap file

1
Find it directly on your filesystem

mindkeeper saves your data locally at:

~/.mindkeeper/mindmap.json
Mac — Finder: Cmd+Shift+G, paste the path above Windows — Explorer address bar: %USERPROFILE%\.mindkeeper\mindmap.json Linux — ~/.mindkeeper/mindmap.json
2
Or ask Claude to hand it to you

In any Claude session with mindkeeper-mcp running, say:

"Export my full mindmap as JSON so I can save it to a file"

Copy the JSON from the response, paste it into a text editor, and save as mindmap.json.

💡

You can also ask Claude to visualize your mindmap inline — try "Show me my mindmap as a Mermaid diagram" or "Draw my mindmap as an ASCII tree". But this page is better: you get zoomable, draggable, interactive exploration that fits your whole map on one screen — something a chat response can't do.
